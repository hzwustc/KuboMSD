# 版本记录

## 1.0.4

- 为 PCG 内部停止条件增加余量，减少重复稀疏乘法导致真残差在阈值附近波动的问题。最终验收容差保持不变。
- 保留初始解已经满足绝对容差时的零次迭代返回。
- 完成 160 原子 In₂O₃ 的算符、全谱对角化、EXACT MSD、stepwise 和 spectral 数值对照。
- 整理独立发布目录、合成示例、测试与使用文档；计算源码保持当前 1.0.4 实现。

## 1.0.3

- 修复 PCG 根据递推残差过早冻结候选收敛列的问题。在原方程真残差未达标时，使用剩余迭代预算继续求解。

## 1.0.2

- 区分 HDF5 的 DeePTB/ABACUS 轨道约定与积分采用的 ABACUS 约定。
- 将构造的 S 和偶极矩变换到输入 H 的基底。
- 更新算符缓存身份，拒绝继续使用缺少基底标记的旧原始 LCAO GPU 缓存。

## 1.0.1

- 修正复数稀疏重叠矩阵的 Ritz 起始向量类型，并调整正定性检查使用的子空间。

## 1.0.0

- 单进程、单 GPU 的 Γ 点算符构造与输运计算。
- 全谱精确解，以及 stepwise、spectral 和预先选择方法的 auto 随机迹接口。
- 非正交度量求解、完整算符缓存、HDF5/NPZ 结果和统计分块输出。
