# 合成示例

| 目录 | 用途 |
| --- | --- |
| `two_level/` | 正交双能级模型，含复数矩阵元 |
| `nonorthogonal/` | 非正交双能级模型，用于度量处理和结果对照 |
| `raw_lcao/` | 从 POSCAR、数值轨道和 HDF5 构造完整算符 |

这些文件用于安装和数值检查。`raw_lcao/X.orb` 为合成轨道，HDF5 为合成哈密顿量，不能用于实际材料计算。

从项目根目录运行 [README](../README.md) 和 [运行说明](../docs/usage.md) 中的命令。计算输出使用新的 `runs/` 子目录，避免覆盖示例输入。
