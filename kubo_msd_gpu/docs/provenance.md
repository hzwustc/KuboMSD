# 代码与测试来源

本版从 `kubo_msd_gpu_v1.0` 的 1.0.4 工作版本整理，保留了 65 个 Python/CUDA 计算源文件。整理范围为文档、示例中的显式基底声明、仓库忽略规则、持续集成和分发清单，未改变计算源码。

GPU 实现沿用 KuboMSD 系列的数值定义和 Python/SciPy 参考模块；双中心积分与早期 `kubo_msd_v1.1` 的 CPU 实现做过独立对照。GPU 运行不导入该 CPU C++ 扩展，分发包也不包含其二进制文件。

`tests/fixtures/exact_original.py` 保留早期 EXACT 参考脚本，用于完整谱缩放问题的回归。文件按原内容保存，测试中核对其 SHA256。其中面向 RSATB 的可选入口并非本项目运行接口；本项目测试只调用其纯数值部分，不要求安装 RSATB。

`tests/data/` 保存合成轨道的 CPU 参考数组。`examples/` 中的 HDF5、NPZ 和 `X.orb` 是合成输入，不是实际材料的赝势或轨道参数。真实 In₂O₃ 的输入和完整验收产物未随仓库分发，[验证记录](validation.md) 仅列出测试条件、结果和适用范围。

本机冻结基线、开发过程文件、虚拟环境和历史输出不属于发布包。依赖这些冻结目录的两项性能/材料脚本也未分发；保留的 `benchmark_transport.py` 只用于参考小模型计时，`validate_tolerance.py` 用于合成模型积分容差检查。

项目暂未指定许可证，也未填写未经确认的作者、机构、仓库地址或引用标识。
