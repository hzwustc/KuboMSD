# 验证记录

本页记录 1.0.4 的测试范围及真实材料对照结果。仓库提供可运行的合成模型测试；真实材料 HDF5 和大型中间文件未随仓库分发。

## 合成模型回归

测试包括能量核与完整谱缩放、非正交基变换、解析小模型、PCG 真残差、GPU 径向表与 s/p/d/f 双中心积分、DeePTB 基底变换、完整算符缓存、精确解、两种随机迹、输出往返读取和失败条件。

运行方式见 [开发与测试](../CONTRIBUTING.md)。CPU 参考测试使用 Python/SciPy；它们不验证 GPU 执行。GPU 测试需要真实 CUDA 设备。安装检查从源码目录之外加载 wheel，并使用空的 JIT 缓存执行首次编译、构造和三条求解路线。

GitHub Actions 配置只运行 CPU 参考测试和打包检查。GPU 验证在有设备的机器上单独进行。

## 160 原子 In₂O₃

验证日期：2026-10-20 至 2026-10-21。算例包含 64 个 In、96 个 O，共 2,848 个轨道；使用实际 dftio HDF5。计算设备为 RTX 5090，软件环境为 Python 3.11、CuPy 13.6.0、NumPy 1.26.4、SciPy 1.12.0。

| 检查 | 结果 |
| --- | --- |
| 构造 H 与独立 Γ 点折叠 | 一致 |
| 构造 S 与 dftio overlap | 最大绝对差 `5.49 × 10⁻⁸` |
| GPU/CPU 全部 2,848 个本征值 | 最大差 `2.05 × 10⁻¹² eV`，使用同一构造 S |
| 全谱范围 | `[-10.079527525, 301.934235691] eV` |
| 两起点 Ritz | 分别在 416、432 维收敛 |
| 自动谱区间 | `[-13.199665157, 305.054373323] eV`，包含独立 CPU 全谱 |
| EXACT MSD 与独立本征态求和 | 最大绝对差 `7.11 × 10⁻¹⁵ Å²` |
| stepwise MSD 与相同随机样本参考 | 最大绝对差 `9.17 × 10⁻¹⁴ Å²` |
| spectral MSD 与相同随机样本参考 | 最大绝对差 `3.08 × 10⁻¹³ Å²` |
| HDF5/NPZ 往返一致性 | EXACT 29、stepwise 26、spectral 32 个数据集通过 |

输运对照采用 Jackson 128 阶、费米能 `8.2003625642 eV` 附近 ±1 eV 的 9 个节点、xyz 方向和 0–0.1 fs 的短时间区间。积分构造容差为 `1e-8`，度量求解 `rtol=1e-13`、最大 4,000 次迭代。随机迹使用 4 个样本、种子 20261020；spectral 的 VAC 积分步长为 0.005 fs。

两种随机迹的参考使用相同随机相位和同一独立本征系统，所以表中误差检验的是实现一致性。相对于完整迹，4 样本 stepwise MSD 的相对 L2 差为 3.14%，spectral 为 10.37%；后者还包含约 0.381% 的完整迹积分偏差。两种方法的误差不能简单互相替代。

这次计算只有一个统计块，无法给出可靠的统计误差估计。原始 H 和 overlap 为 float32；双精度求解器的一致性不代表 DFT 输入具有同样精度。输运只计算 Γ 点，不能代替原 SCF 的 3×3×3 网格积分。矩数、长时间、样本数及材料输运收敛尚需另做测试。

## 800 原子块体及显存限制

先前的 800 原子 In₂O₃ 块体包含 14,240 个轨道。1.0.4 的块体随机迹运行在前置 Ritz 检查阶段失败，未产生完整 MSD；160 原子算例的成功不能视为已解决该问题。

按当前预算策略，2,848 轨道的稠密本征系统及工作区约需 1.21 GiB，14,240 轨道约需 30.22 GiB，均未计入已有算符等开销。后者在本机曾被资源检查拒绝。较小算例可运行，并不意味着同一 GPU 能容纳较大算例的全谱对角化。

没有据此宣称 GPU 加速比，也没有 A100、多 k 点或多 GPU 验证结果。
